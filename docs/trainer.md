Hydraulic Trainer & Designer

An interactive companion to this course — size, analyze, and visualize the hydraulics of the same lift platform the lessons build. Use Design mode to size the cylinder, pump, motor, lines, and relief valve from a target load and speed, and Analyze mode to check pressures, flows, buckling, and cavitation against an animated ISO 1219 schematic.
